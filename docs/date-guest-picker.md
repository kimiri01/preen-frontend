# 날짜·인원 선택기 (Moon)

브랜치 feature/date-guest-picker_Moon. 선행 별점 필터 브랜치에서 분리한 로컬 작업입니다.

- 브라우저 기본 날짜 선택기 사용. 한국 시간 오늘을 최소 체크인으로 지정합니다.
- 체크아웃은 체크인 다음 날부터 가능합니다. 체크인을 바꾸거나 비우면 충돌하는 체크아웃을 비웁니다.
- 입력 유효성을 별도 함수로 검사해 URL로 잘못된 조건을 전달해도 적용하지 않습니다.
- 성인/객실1개 기준. 최대 인원은 해당 숙소 활성 객실의 maxCapacity 중 최댓값입니다.
- 인원 직접 입력 및 증감 버튼 제공. 범위 밖 직접 입력은 안내하고 적용을 막습니다.
- 날짜·인원은 기존 checkIn/checkOut/guestCount URL 약속을 사용합니다.
- 음악 탭·새로고침에서도 유지하고 목록 복귀 시 전달합니다.
- 조건 적용은 입력 확인과 객실 영역 이동만 수행합니다. 실시간 재고·가격 계산·예약 생성은 포함하지 않습니다.

테스트: node --test tests/staySelection.test.mjs (3개 통과), npm run build 통과.
한국 날짜 전환/윤년/연도 경계, 과거·동일·역전·잘못된 날짜, 인원 범위 검사.
실행 화면에서 체크인 변경 시 체크아웃 초기화, 최대4명 증가 제한,
잘못된 조건 적용 차단, 음악 탭·새로고침 후 값 유지 확인.

아동/유아, 복수 객실, 숙박 가능 기간 정책은 팀 명세 확정 후 추가해야 합니다.
실제 예약 서버에서도 날짜·정원·재고를 다시 검사해야 하며 이 화면의 검사만 신뢰하면 안 됩니다.

## 부가 기능
오늘부터1박/다가오는 주말 빠른 선택과 날짜·인원 초기화 추가. 초기화는 날짜를 비우고 성인 기본2명(최대정원1명 숙소는1명)으로 돌립니다.
객실별 정원 충족/초과 및 정원 충족 객실 유형 수를 안내합니다. 실제 재고나 빈방 수가 아닙니다.
주말 토요일/일요일 경계 테스트 포함 총4개 통과. 실행 화면에서 빠른 선택·초기화 확인.
