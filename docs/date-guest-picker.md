# STAY-005 날짜·인원 선택기 — 최신 구현

작업 위치: feature/stay-date-validation_Moon. 같은 기능 문서를 최신 상태로 갱신합니다.

- 한국 시간 오늘부터 체크인 가능. 체크아웃은 다음 날부터 최대30박까지.
- 날짜 변경 시 기존 체크아웃이 새 범위를 벗어나면 초기화. 잘못된 URL의31박도 안내하고 적용 차단.
- 박수 표시, 오늘1박/이번주말/초기화, 인원 직접입력·증감 및 활성 객실 최대정원 검사.
- checkIn/checkOut/guestCount URL 유지. 음악 탭/새로고침/목록 복귀에도 전달.
- 객실 정원 충족 안내는 실제 날짜별 잔여 객실 수가 아닙니다.

검증: 날짜·인원 테스트5개(정확히30박/31박/연도·윤년 경계 포함), Spotify입력2개, 총7개 및 빌드 통과.

남은 연결: 팀 availability API/날짜별 판매가·잔여 재고·예약 생성. 현재 날짜 선택은 비교용이며 예약 버튼은 비활성.
팀 예약 브랜치에도 availability 경로가 없어 연결 완료로 처리하지 않습니다. 아동/유아·복수 객실은 범위 제외.
